چطور سر هم می‌شود؟


هشت لایه، از پایین به بالا. هر مرحله یک لایه به قبلی اضافه می‌کند. قطعه‌ها در یک دستگاه مختصات یکسان کشیده شده‌اند، برای همین هر ترکیبی روی هم درست می‌نشیند.





چند نمونه


همه با همان بدنه و فقط با عوض کردن چند عدد ساخته شده‌اند. هر کدام یک «ست» است.





انیمیشن‌ها چطور کار می‌کنند؟




هیچ ویدیو یا فایل متحرکی در کار نیست. برنامه ۶۰ بار در ثانیه چند عدد را حساب می‌کند و به لایه‌ها می‌دهد:


// each state is just a function of time t (seconds)
idle:      dy = sin(t*2)*2.2                 // breathing
wave:      armL = 150deg + sin(t*9)*14       // waving
ring:      wobble = sin(t*30)*7              // shaking while ringing
celebrate: dy = -abs(sin(t*5))*34            // jump + squash on landing
talk:      mouth = .3 + .7*abs(sin(t*11))    // mouth opens and closes
// + a blink every 2-5 s, and the face follows the user's finger


همین فرمول‌ها در Compose هم به همین شکل نوشته می‌شوند. هر حالت جدید (مثلاً «غمگین» یا «دویدن») فقط یک خط فرمول است. پس هر حالتی که نمونه‌های تو داشتند (پرواز، شیپور، فکر، خواب، جشن) ساختنی است.

پیشنهاد من: برای شروع همین روش کدی. چون سبک است، بدون وابستگی است و همه‌چیز (حالت‌ها، قطعه‌ها، رنگ‌ها، آیتم‌های مناسبتی و قفل‌دار) در دست خودمان می‌ماند. اگر روزی طراحی خواست حرکات خیلی پیچیده و سینمایی بسازد، همین SVGها را می‌توان به Rive برد (Rive از SVG ورودی می‌گیرد) و بدنه را عوض کرد. یعنی کار فعلی هدر نمی‌رود.
