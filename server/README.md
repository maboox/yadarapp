# سرور یادار

سرور کوچک یادار: ورود با شمارهٔ موبایل، موجودی توکن، و واسطهٔ هوش مصنوعی (سرویس‌های سازگار با OpenAI مثل
لیارا، اول‌ای‌آی و OpenRouter). روی [PocketBase](https://pocketbase.io) ساخته شده و پنل مدیریتش در آدرس `/_/` است.

## چیزهایی که سرور انجام می‌دهد

- **ورود:** کد پیامکی (کاوه‌نگار یا sms.ir) و یک شمارهٔ تست با کد ثابت برای داور کافه‌بازار.
- **توکن:** هر درخواست هوش مصنوعی هزینهٔ واقعی‌اش را از روی مصرف مدل حساب می‌کند و به توکن تبدیل می‌کند (با ضریب سود). کاربر بی‌موجودی خطای 402 می‌گیرد.
- **مدل:** به ترتیب «مدل اختصاصی کاربر ← مدل پلن ← مدل پیش‌فرض تنظیمات».
- **چند سرویس‌دهنده:** به ترتیب `priority` امتحان می‌شوند. اگر یکی خطا داد، سراغ بعدی می‌رود.
- **حریم خصوصی:** متن درخواست‌ها ذخیره نمی‌شود. فقط عددها (مدل، تعداد توکن، هزینه) در جدول `usage` می‌ماند.

## راه‌اندازی روی لیارا (قدم به قدم)

1. **ساخت برنامه:** در [لیارا](https://console.liara.ir) یک برنامه از نوع **Docker** بساز، مثلاً با نام `yadar-api`.
   اگر نام دیگری گذاشتی، همان نام را در فایل `liara.json` هم بنویس.
2. **دیسک:** در همان برنامه، از بخش «دیسک‌ها» یک دیسک با نام `data` بساز (۱ گیگ کافی است). دیتابیس اینجا ذخیره می‌شود و با هر به‌روزرسانی پاک نمی‌شود.
3. **متغیرهای محیطی:** از بخش «تنظیمات ← متغیرها» این‌ها را اضافه کن:

   | نام | مقدار |
   |---|---|
   | `ADMIN_EMAIL` | ایمیل ورود به پنل مدیریت |
   | `ADMIN_PASSWORD` | رمز قوی برای پنل (حداقل ۱۰ حرف) |
   | `OTP_SECRET` | یک رشتهٔ تصادفی طولانی (مثلاً ۴۰ حرف) |
   | `SMS_PROVIDER` | `kavenegar` یا `smsir` |
   | `KAVENEGAR_API_KEY` و `KAVENEGAR_TEMPLATE` | اگر کاوه‌نگار: کلید API و نام قالب تأییدشده (قالب باید `%token` داشته باشد) |
   | `SMSIR_API_KEY` و `SMSIR_TEMPLATE_ID` | اگر sms.ir: کلید API و شمارهٔ قالب (پارامتر قالب `CODE`؛ با `SMSIR_PARAM` قابل تغییر) |
   | `REVIEW_PHONE` و `REVIEW_CODE` | اختیاری: شمارهٔ تست و کد ثابت ۵ رقمی برای داور کافه‌بازار |

4. **فایل سرور:** فایل `yadar-server-xxxxxxx.zip` را از بخش Releases گیت‌هاب (`server-<نام برنچ>`) دانلود و از حالت فشرده خارج کن.
5. **ارسال به لیارا:** [ابزار خط فرمان لیارا](https://docs.liara.ir/cli/install/) را نصب کن، داخل همان پوشه `liara login` و بعد `liara deploy` را بزن.
   این پوشه فقط یک فایل اجرایی آماده دارد و موقع نصب چیزی از خارج دانلود نمی‌شود.
6. **ورود به پنل:** آدرس `https://<نام-برنامه>.liara.run/_/` را باز کن و با `ADMIN_EMAIL` و `ADMIN_PASSWORD` وارد شو.

## راه‌اندازی روی سرور خودت (به‌جای لیارا)

سرور فقط یک فایل اجرایی است و روی هر سرور لینوکسی (اوبونتو، دبیان و…) اجرا می‌شود. پیش‌نیاز ندارد و دیتابیس هم داخل خودش است.

**چیزهایی که لازم داری:**
- یک سرور لینوکس با IP ثابت. ۱ هسته و ۱ گیگ رم کافی است.
- یک دامنه (مثلاً از nic.ir) و یک زیردامنه مثل `api.example.ir` که رکورد A آن به IP سرور اشاره کند.
- پورت‌های ۸۰ و ۴۴۳ باز.

**قدم‌ها:**
1. **دریافت فایل:** `yadar-server-selfhosted-xxxxxxx.zip` را از Releases (`server-<نام برنچ>`) بگیر و روی سرور ببر. فایل `yadar-server` برای پردازنده‌های معمولی (amd64) است و `yadar-server-arm64` برای ARM.
2. **نصب:**
   ```bash
   sudo useradd --system --home /opt/yadar --shell /usr/sbin/nologin yadar
   sudo mkdir -p /opt/yadar/pb_data
   sudo cp yadar-server /opt/yadar/ && sudo chmod +x /opt/yadar/yadar-server
   sudo chown -R yadar:yadar /opt/yadar
   ```
3. **متغیرها:** `self-hosted/yadar.env.example` را در `/etc/yadar.env` کپی کن، مقدارها را پر کن (همان جدول بخش لیارا)، و دسترسی را ببند: `sudo chmod 600 /etc/yadar.env`.
4. **اجرای دائمی:** `self-hosted/yadar.service` را در `/etc/systemd/system/` کپی کن و بزن:
   `sudo systemctl daemon-reload && sudo systemctl enable --now yadar`
   با `systemctl status yadar` و `journalctl -u yadar -f` وضعیت و لاگ را می‌بینی.
5. **HTTPS:** [Caddy](https://caddyserver.com/docs/install) را نصب کن، `self-hosted/Caddyfile` را در `/etc/caddy/Caddyfile` بگذار، دامنه‌ات را جای `api.example.ir` بنویس و `sudo systemctl reload caddy` را بزن.
   Caddy گواهی HTTPS را خودش می‌گیرد و تمدید می‌کند. اگر گرفتن گواهی از داخل ایران مشکل داشت، دامنه را پشت CDN ابرآروان ببر و SSL را آنجا روشن کن.
6. **ورود به پنل:** `https://api.example.ir/_/`
7. **پشتیبان‌گیری:** کل اطلاعات در پوشهٔ `/opt/yadar/pb_data` است. از آن مرتب نسخه بگیر. پنل مدیریت هم بخش Backups دارد.
8. **به‌روزرسانی:** فایل `yadar-server` جدید را جایگزین کن و بزن `sudo systemctl restart yadar`.

**نکته:** سرور داخلی باید به سرویس هوش مصنوعی دسترسی داشته باشد. اول‌ای‌آی و لیارا داخلی‌اند و مشکلی نیست، ولی OpenRouter از سرور داخلی کار نمی‌کند.

## تنظیم در پنل مدیریت

- **providers (سرویس‌دهنده‌ها):** یک ردیف برای هر سرویس.
  - `name`: یک نام دلخواه.
  - `base_url`: برای اول‌ای‌آی `https://api.avalai.ir/v1`. برای لیارا آدرسی که پنل هوش مصنوعی لیارا می‌دهد.
  - `api_key`: کلید آن سرویس.
  - `priority`: ۱، ۲، … (عدد کمتر زودتر امتحان می‌شود).
  - `enabled`: روشن.
  - **بررسی مدل‌ها:** تیک `check_now` را بزن و ذخیره کن. در `check_result` می‌بینی کدام مدل‌ها در آن سرویس هستند (✓) و کدام نیستند (✗)، با پیشنهاد نام‌های مشابه.
  - **نام متفاوت مدل:** اگر سرویس اسم مدل را جور دیگری نوشته، در `model_map` بنویس، مثلاً `{"deepseek/deepseek-v4-flash": "deepseek-v4-flash"}`.
- **settings:**
  - `token_usd`: ارزش هر توکن به دلار (پیش‌فرض ۰٫۰۰۲۵، یعنی تقریباً یک تسک).
  - `markup`: ضریب روی هزینه (پیش‌فرض ۱؛ سود در قیمت بسته‌هاست).
  - `signup_tokens`: هدیهٔ ثبت‌نام (۱۰).
  - `default_text_model` و `default_audio_model`: مدل‌های پیش‌فرض.
  - `ai_enabled`: کلید قطع اضطراری همهٔ درخواست‌های هوش مصنوعی.
- **models:** قیمت هر مدل (دلار به ازای یک میلیون توکن، یا به ازای هر دقیقه صدا برای مدل‌های `transcription`). قیمت‌های اولیه تخمینی‌اند و باید با قیمت سرویس‌دهنده یکی شوند.
- **plans:** پلن‌ها با مدل‌های جدا. در ردیف هر کاربر (`users`) می‌شود پلن، مدل اختصاصی، `balance` (موجودی) و `unlimited` (نامحدود) را دستی عوض کرد.
- **usage:** گزارش هر درخواست: کاربر، مدل، هزینهٔ دلاری و توکن کسرشده.

## ورود و خرید با کافه‌بازار

همه در پنل مدیریت سرور، جدول **settings** پر می‌شود (یا با متغیرهای محیطی هم‌نام با حروف بزرگ):

| فیلد | از کجا |
|---|---|
| `public_url` | آدرس سرور، مثلاً `https://yadar.pish.run` |
| `bazaar_client_id` و `bazaar_client_secret` | پیشخان بازار ← برنامه ← «ورود با بازار» |
| `bazaar_api_token` | پیشخان بازار ← برنامه ← «API پیشخان» ← دریافت توکن |

**ورود درون‌برنامه‌ای (روش فعلی برنامه):** برنامه شناسهٔ حساب را از اپ بازارِ روی گوشی می‌گیرد و به `/bazaar/app-login`
می‌فرستد؛ تنظیمی لازم ندارد. هدیهٔ ثبت‌نام برای هر گوشی یک بار و برای هر آدرس IP حداکثر ۵ بار در روز داده می‌شود (جدول **gifts**).
اگر سوءاستفاده دیدی، `app_login_disabled` را در settings روشن کن.

**بررسی خرید با امضا:** کلید RSA پیشخان («پرداخت درون‌برنامه‌ای» ← کلید RSA) را در `bazaar_rsa_key` بگذار. سرور امضای بازار
روی هر خرید را خودش بررسی می‌کند و لازم نیست به بازار وصل شود؛ مصرف خرید را برنامه انجام می‌دهد.
اگر `bazaar_api_token` هم باشد و امضا نیاید، خرید با API بازار بررسی می‌شود.

**ورود در وب (فعلاً بازار به آن جواب 403 می‌دهد):** در همان صفحهٔ «ورود با بازار» در پیشخان، این Redirect URL را اضافه کن:
`<public_url>/api/yadar/bazaar/callback`

بسته‌های توکن در جدول **packs** هستند (`sku` باید دقیقاً همان شناسهٔ محصول در «پرداخت درون‌برنامه‌ای» پیشخان باشد).
محصول‌ها را در پیشخان از نوع **مصرفی** بساز. هر خرید را سرور با API بازار بررسی می‌کند، فقط یک بار و فقط
برای حسابی که خرید را انجام داده توکن اضافه می‌کند و بعد خرید را در بازار مصرف می‌کند. خریدها در جدول **purchases** دیده می‌شوند.

**سرور خارج از ایران:** بازار به خیلی از آدرس‌های خارجی جواب 403 می‌دهد. در این حالت متغیر `BAZAAR_PROXY` را روی یک پراکسی داخل
ایران بگذار (مثلاً `socks5://user:pass@1.2.3.4:1080` یا `http://user:pass@1.2.3.4:3128`)؛ فقط درخواست‌های بازار از آن رد می‌شوند.

اسم بسته‌هایی که مجاز به خرید هستند با `BAZAAR_PACKAGES` عوض می‌شود (پیش‌فرض: `com.yadavard.app,com.yadavard.app.plus`).

## اتصال برنامه

اگر نام برنامه در لیارا `yadar-api` نیست، در برنامهٔ یادار به «تنظیمات ← دستیار هوشمند ← پیشرفته ← آدرس سرور یادار» برو
و آدرس `https://<نام-برنامه>.liara.run` را ذخیره کن.

## توسعه

```bash
cd server
go test ./...
SMS_PROVIDER=dev ADMIN_EMAIL=a@b.c ADMIN_PASSWORD=Secret12345 go run . serve --http=127.0.0.1:8090
```
در حالت `SMS_PROVIDER=dev` کد ورود در جواب درخواست و در لاگ سرور می‌آید و پیامکی فرستاده نمی‌شود.
