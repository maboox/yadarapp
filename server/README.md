# سرور یادار

سرور کوچک یادار: ورود با شمارهٔ موبایل، موجودی توکن، و واسطهٔ هوش مصنوعی (سرویس‌های سازگار با OpenAI مثل
لیارا، اول‌ای‌آی و OpenRouter). روی [PocketBase](https://pocketbase.io) ساخته شده و پنل مدیریتش در آدرس `/_/` است.

## چیزهایی که سرور انجام می‌دهد

- **ورود:** کد پیامکی (کاوه‌نگار یا sms.ir) و یک شمارهٔ تست با کد ثابت برای داور کافه‌بازار.
- **توکن:** هر درخواست هوش مصنوعی هزینهٔ واقعی‌اش را از روی مصرف مدل حساب می‌کند و به توکن تبدیل می‌کند (با ضریب سود). کاربر بی‌موجودی خطای 402 می‌گیرد.
- **مدل:** به ترتیب «مدل اختصاصی کاربر ← مدل پلن ← مدل پیش‌فرض تنظیمات».
- **چند سرویس‌دهنده:** به ترتیب `priority` امتحان می‌شوند. اگر یکی خطا داد، سراغ بعدی می‌رود.
- **حریم خصوصی:** متن درخواست‌ها ذخیره نمی‌شود. فقط عددها (مدل، تعداد توکن، هزینه) در جدول `usage` می‌ماند.

## راه‌اندازی روی لیارا (قدم به قدم)

1. **ساخت برنامه:** در [لیارا](https://console.liara.ir) یک برنامه از نوع **Docker** بساز، مثلاً با نام `yadar-api`.
   اگر نام دیگری گذاشتی، همان نام را در فایل `liara.json` هم بنویس.
2. **دیسک:** در همان برنامه، از بخش «دیسک‌ها» یک دیسک با نام `data` بساز (۱ گیگ کافی است). دیتابیس اینجا ذخیره می‌شود و با هر به‌روزرسانی پاک نمی‌شود.
3. **متغیرهای محیطی:** از بخش «تنظیمات ← متغیرها» این‌ها را اضافه کن:

   | نام | مقدار |
   |---|---|
   | `ADMIN_EMAIL` | ایمیل ورود به پنل مدیریت |
   | `ADMIN_PASSWORD` | رمز قوی برای پنل (حداقل ۱۰ حرف) |
   | `OTP_SECRET` | یک رشتهٔ تصادفی طولانی (مثلاً ۴۰ حرف) |
   | `SMS_PROVIDER` | `kavenegar` یا `smsir` |
   | `KAVENEGAR_API_KEY` و `KAVENEGAR_TEMPLATE` | اگر کاوه‌نگار: کلید API و نام قالب تأییدشده (قالب باید `%token` داشته باشد) |
   | `SMSIR_API_KEY` و `SMSIR_TEMPLATE_ID` | اگر sms.ir: کلید API و شمارهٔ قالب (پارامتر قالب `CODE`؛ با `SMSIR_PARAM` قابل تغییر) |
   | `REVIEW_PHONE` و `REVIEW_CODE` | اختیاری: شمارهٔ تست و کد ثابت ۵ رقمی برای داور کافه‌بازار |

4. **فایل سرور:** فایل `yadar-server-xxxxxxx.zip` را از بخش Releases گیت‌هاب (`server-<نام برنچ>`) دانلود و از حالت فشرده خارج کن.
5. **ارسال به لیارا:** [ابزار خط فرمان لیارا](https://docs.liara.ir/cli/install/) را نصب کن، داخل همان پوشه `liara login` و بعد `liara deploy` را بزن.
   این پوشه فقط یک فایل اجرایی آماده دارد و موقع نصب چیزی از خارج دانلود نمی‌شود.
6. **ورود به پنل:** آدرس `https://<نام-برنامه>.liara.run/_/` را باز کن و با `ADMIN_EMAIL` و `ADMIN_PASSWORD` وارد شو.

## تنظیم در پنل مدیریت

- **providers (سرویس‌دهنده‌ها):** یک ردیف برای هر سرویس.
  - `name`: یک نام دلخواه.
  - `base_url`: برای اول‌ای‌آی `https://api.avalai.ir/v1`. برای لیارا آدرسی که پنل هوش مصنوعی لیارا می‌دهد.
  - `api_key`: کلید آن سرویس.
  - `priority`: ۱، ۲، … (عدد کمتر زودتر امتحان می‌شود).
  - `enabled`: روشن.
  - **بررسی مدل‌ها:** تیک `check_now` را بزن و ذخیره کن. در `check_result` می‌بینی کدام مدل‌ها در آن سرویس هستند (✓) و کدام نیستند (✗)، با پیشنهاد نام‌های مشابه.
  - **نام متفاوت مدل:** اگر سرویس اسم مدل را جور دیگری نوشته، در `model_map` بنویس، مثلاً `{"deepseek/deepseek-v4-flash": "deepseek-v4-flash"}`.
- **settings:**
  - `token_usd`: ارزش هر توکن به دلار (پیش‌فرض ۰٫۰۰۱).
  - `markup`: ضریب سود (پیش‌فرض ۱٫۵).
  - `signup_tokens`: هدیهٔ ثبت‌نام (۱۰۰).
  - `default_text_model` و `default_audio_model`: مدل‌های پیش‌فرض.
  - `ai_enabled`: کلید قطع اضطراری همهٔ درخواست‌های هوش مصنوعی.
- **models:** قیمت هر مدل (دلار به ازای یک میلیون توکن، یا به ازای هر دقیقه صدا برای مدل‌های `transcription`). قیمت‌های اولیه تخمینی‌اند و باید با قیمت سرویس‌دهنده یکی شوند.
- **plans:** پلن‌ها با مدل‌های جدا. در ردیف هر کاربر (`users`) می‌شود پلن، مدل اختصاصی، `balance` (موجودی) و `unlimited` (نامحدود) را دستی عوض کرد.
- **usage:** گزارش هر درخواست: کاربر، مدل، هزینهٔ دلاری و توکن کسرشده.

## اتصال برنامه

اگر نام برنامه در لیارا `yadar-api` نیست، در برنامهٔ یادار به «تنظیمات ← دستیار هوشمند ← پیشرفته ← آدرس سرور یادار» برو
و آدرس `https://<نام-برنامه>.liara.run` را ذخیره کن.

## توسعه

```bash
cd server
go test ./...
SMS_PROVIDER=dev ADMIN_EMAIL=a@b.c ADMIN_PASSWORD=Secret12345 go run . serve --http=127.0.0.1:8090
```
در حالت `SMS_PROVIDER=dev` کد ورود در جواب درخواست و در لاگ سرور می‌آید و پیامکی فرستاده نمی‌شود.
